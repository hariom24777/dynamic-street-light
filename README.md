# Dynamic Street Light

A React + Firebase dashboard for monitoring and analyzing street light energy usage and device status. This project provides a simple UI to view energy analytics, project overview, and realtime data powered by Firebase.

## Features
- Realtime device data via Firebase
- Energy analytics and charts
- Project overview and navigation

## Tech Stack
- Frontend: React, Vite
- Styling: Tailwind CSS
- Data & auth: Firebase
